# index.html 重新設計 — Mockup 沿革

存放 `docs/index.html`（族群總覽頁）重新設計過程中做的 HTML mockup，依時間序保留每一版，方便換平台/換 session 後接續討論，不用重做。用瀏覽器直接開啟 `.html` 檔即可看外觀（不需要跑 server）。

## 版本

1. **2026-07-07-index-v1-flat-ranklist.html** — 第一版方向定案：扁平排行清單取代三層卡片，兩層點擊，左側排行清單＋右側明細面板，桌機/手機兩種版面。深色系（沿用 chips.html/patterns.html 既有色票）。Cody 認可此方向。

2. **2026-07-08-index-v2-anomaly-dark.html** — 新增「異動族群」模組：獨立於例行排行之外，只顯示同時符合多重訊號的族群。兩種訊號類型：
   - **爆量暴衝**：`vol_ratio ≥ 1.5` 且 `|昨日排名-今日排名| ≥ 10`
   - **連續穩步噴出**：`streak ≥ 5`（連漲≥5日）且 `cum7 > cum5 > cum3`（累積報酬持續加速）

   仍是深色系。

   - **熱區格（Heatmap）**：41 族群一次攤開，色塊深淺=漲跌幅度
   - **發散長條排行**：由中線延伸的橫條，長度=漲跌幅度，由上到下排序

   **Cody 反饋「資訊不夠多」**——具體提出想看到的資訊：突然爆發的族群跟上週的差異，以及這週表現好的族群上週表現如何。

7. **2026-07-14-index-v7-signal-fidelity.html** — Debugger review v6 後提出 5 個具體問題，逐項修正（設計評論見同日 `debug-tasks.md`/對話紀錄，未另開 spec）：

   - **熱區格沒有任何判讀說明、看不出排名**：加一條圖例說明條（色塊=今日漲跌、角標=排名、底部折線=加速度）+ 每格右上角加排名角標。
   - **長條排行族群名可能截斷**：欄寬 112px→132px，加 `title` 屬性當 fallback；表頭改 sticky，捲動到後段仍看得到欄名。
   - **異動族群橫向捲動沒有視覺提示**：加右側漸層遮罩 + 「可左右滑動」提示文字。

17/18. **2026-07-15-index-v17-drawer-panel.html** / **2026-07-15-index-v18-inline-expand.html**
    — Cody 反饋 v16 的點開面板「拉到下面去很不直覺」：面板固定接在整個熱區格最後面，點越前面
    排的卡片，視線要滑過的距離越長，跟點擊位置完全脫節。做兩版方向比較，供 Cody 選：
    - **v17（右側滑出 drawer）**：點卡片後面板從螢幕右側固定位置滑出（`position:fixed` +
      `transform` 動畫），背後加半透明遮罩，點遮罩或收合按鈕關閉。**優點**：不管點哪張卡視線
      移動距離都一樣，完全不用捲動頁面，連續點不同族群體驗一致。**代價**：會遮住/擠壓右側一
      部分熱區格內容；窄螢幕（&lt;640px）面板佔滿全寬，接近全螢幕覆蓋。實作簡單（固定定位，
      不用算版面）。
    - **v18（卡片原地展開）**：面板動態插入到「被點卡片所在那一整排」正下方（JS 用
      `offsetTop` 分組算出同一排的卡片，`grid-column:1/-1` 撐滿整排寬度插進去）。**優點**：
      空間錨定感最好，點哪裡就在哪裡展開，不遮住任何內容；點異動族群卡片也會自動捲到熱區格
      對應那一排展開，直接展示兩區塊指向同一份資料。**代價**：實作邏輯較複雜（欄數隨螢幕寬度
      變化的 row 分組計算）；連續點不同族群時，版面高度會因為展開位置不同而一直跳動。
    - 兩版都改掉 v16 用 `.hidden` class 切換顯示/隱藏的做法：v17 改用 `transform` 滑動狀態，
      v18 改用動態插入/移除 DOM 節點（因為面板要出現的位置每次都不一樣，不能是固定佔位的
      隱藏節點）。
