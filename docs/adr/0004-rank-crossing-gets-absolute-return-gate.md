# 「排名進出榜」加上絕對報酬閘門，不是純相對排名

**背景**：`0003` 論證了「排名進出榜」該是純粹的相對排名訊號，即使跟「轉折點列表」（自身動能）
結果矛盾也不合併——矛盾本身是有意義的資訊。實際上線後 Cody 看到真實案例：全市場普遍走弱的
一週，「散熱」上週排名#24（跌9.6%），這週排名#1（但自身仍是跌1.21%，只是跌最少），被列進
「剛進榜」。數字沒有算錯，但呈現方式造成誤導——使用者會直覺解讀成「散熱在噴」，而不是「散熱
跌最少」。

**決定**：在「剛進榜／剛掉出榜」的判定上，除了原本「跨過前10名門檻」，加一個絕對報酬閘門：
剛進榜需本週自身5日複利報酬 > 0%；剛掉出榜需 < 0%。門檻值0%，不通過閘門的跨榜從清單消失
（不算誤判、也不另外歸類）。範圍只限 `find_rank_crossings()`；`calc_meta_rank_history()` 的
排名計算本身、`in_top10_this_week`/`consecutive_weeks_in_top10`（歷史出現紀錄用）都不受
影響，維持純排名。

**why**：這不是推翻 `0003` 的結論——`0003` 討論的是「要不要跟另一個獨立訊號（轉折點/tier）
合併」，這裡是「同一個訊號（排名）內部要不要有自我一致性檢查」，範疇不同。`0003` 的核心
（排名跟tier矛盾本身有意義、不用合併）依然成立；這次修的是「排名跨榜」這個單一訊號自己內部
會不會誤導人——全市場一起走弱時，「相對最好」可能絕對值仍是負的，直接呈現成「進榜」對讀者
來說太反直覺，加閘門後「剛進榜」才真正代表「這個族群本身也轉正了，而且相對表現最好」。

**代價**：全市場單邊走勢（普遍大漲或普遍大跌）時，「剛進榜/剛掉出榜」清單可能會因為閘門而
變空——即使排名確實有跨榜。這是刻意的：情願清單暫時空白，也不要顯示會誤導的假訊號。
