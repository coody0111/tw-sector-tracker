# 跨頁視覺系統拓展設計

## 1. 目標

將 `index.html` 已驗證的暗色交易研究介面延伸到 `chips.html`、`patterns.html`、`momentum.html`，讓四個靜態頁面共享同一套視覺語言與互動習慣，同時保留各頁不同的研究任務與資料語意。

本次優先處理視覺與資訊層級；不改變既有資料判斷邏輯。跳空納入型態頁的 UI 與資料欄位預留，掃描邏輯與回測可在同一版實作。

## 2. 已確認決策

### 共用體驗

- 共用 CSS token、topbar、nav、section、card、badge、data-row、expand-panel、empty-state。
- 共用「分組卡片＋原地展開」互動，但各頁可使用不同 DOM 結構。
- 桌面版 compact card 顯示 2–3 行；手機版顯示 1–2 行。
- 頁首共用標題、用途、資料日期、資料狀態與摘要骨架；各頁自訂摘要數字。
- 全頁搜尋搭配方向／訊號／資料日期篩選。
- 真實數據使用高對比實色；分類、評分與未充分驗證的衍生標籤使用低對比或虛線樣式。
- 每頁產生正式 HTML，桌面與手機各驗證一次。

### chips

- 第一屏左「法人動向」、右「融資風險」。
- 族群狀態分為資金流入、資金流出、價格背離；只放籌碼指標，不複製 index 的族群績效指標。
- 族群卡片顯示外資與投信分開的原始數字；點擊後展開個股籌碼與趨勢證據。
- 只顯示有事件的項目；空狀態要說明原因、資料日期與下一步。
- 預留統一事件模型，未來可加入分點掃盤異常；初期分點資料放在個股展開證據層。

### patterns

- 預設「研究總覽」同頁顯示四個可收合研究區：值得研究、型態分區、META 熱區、避開／觀察；原有 tabs 保留作為深度瀏覽與 hash 相容入口。
- 研究優先級只代表研究狀態，不等於買賣建議；多頭／空頭是方向 badge。
- 個股由大表格改為 compact card；第一層看即日證據，交易計畫與完整欄位進入展開層。
- 型態勝率獨立顯示在型態分組摘要與頁尾回測區，不直接轉成個股排序。

### momentum

- 今日新訊號在上，本週候選在下；同層先按訊號新鮮度，再按分數排序。
- 主區只顯示符合市場環境與權限的可行動候選；被規則攔截的項目保留於風險區。
- 保留既有權限／市場環境 banner。

### 跳空

- 事件型態只分向上跳空／向下跳空，作為獨立 badge，可與結構型態並存。
- 同時計算完整缺口與開盤跳幅：向上缺口 `(today_low - yesterday_high) / yesterday_high`；向下缺口 `(yesterday_low - today_high) / yesterday_low`；開盤跳幅以今日開盤相對昨日收盤計算。
- 缺口幅度至少 3% 才列為主訊號。
- 今日成交量至少為 20 日均量 1.5 倍才算量能確認。
- 訊號分為當日新訊號與未回補追蹤；回補狀態分盤中回補與收盤回補。
- 卡片顯示方向、缺口幅度、今日漲跌與量能；展開層可放缺口邊界與回補細節。
- 回測獨立統計方向報酬、勝率與回補天數；樣本不足時不顯示假精確數字。

## 3. 非目標

- 不引入前端框架或新 UI 套件。
- 不複製 index 的族群價格指標到 chips。
- 不把型態勝率混入綜合評分或買賣推薦。
- 不手動修改 `docs/*.html`；產物由 generator 產生。

## 4. 驗收條件

1. 四頁 topbar、nav、背景、邊框、字體、accent 與狀態色一致。
2. chips、patterns、momentum 不再依賴大型橫向主表格作為第一層主要瀏覽介面。
3. compact card 在桌面顯示 2–3 行，手機顯示 1–2 行，點擊後可原地展開。
4. 空資料與資料不完整狀態不留白，且不把估算分類誤呈為原始數據。
5. 跳空欄位與 UI 預留可由後續掃描器直接接入，且不破壞既有型態 badge。
6. 既有 generator 測試與新增契約測試通過；HTML 產物可正常生成。
7. 桌面與窄螢幕沒有水平溢出、關鍵欄位被裁切或無法操作的互動。
