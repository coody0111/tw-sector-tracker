# 「排名進出榜」跟「轉折點列表」並存，不合併成一個訊號

**背景**：新設計的「排名進出榜」（族群這週跟上週相比，排名有沒有跨過前10門檻）跟既有的
「轉折點列表」（族群的動能分級 tier 上週跟這週相比有沒有換級）都是週尺度、都在「族群近況」
區塊底下，直覺上像是同一件事的兩種講法，一開始討論時也認真考慮過合併成一個訊號。

**決定**：兩個訊號並存，不合併，各自成獨立子類別。

**why**：兩者答的是不同問題——動能分級只看族群自己的連漲/連跌天數跟本週比上週的加速度，
完全不管其他族群；排名純粹是跟其他41個族群比較的相對名次。兩者可能同時出現矛盾結果
（例如大盤全面大漲、某族群自己也在加速，但因為其他族群漲更多，排名反而下滑）——這種
矛盾正是有意義的資訊，不是需要消除的雜訊。合併成一個指標只會讓這個矛盾被抹平、資訊量
變少，且沒有客觀方式決定「兩者衝突時聽誰的」。專案本身也有「同一時間尺度、不同角度分開
呈現」的先例（異動族群 vs 族群近況，日尺度 vs 週尺度），這裡是同一個模式的延伸。

**代價**：使用者要理解兩個相關但不同的訊號，UI 上需要清楚的文案／說明避免誤會成重複資訊
（已經是族群近況區塊既有的「角色說明」慣例在處理的問題）。
