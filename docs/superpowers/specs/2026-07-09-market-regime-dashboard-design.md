# 大盤分級儀表板（Market Regime Dashboard）— Phase 1

**日期**：2026-07-09
**範圍**：新增大盤五級分類 + 資金集中度診斷，Phase 1 只做「大盤層級」，不含個股五級強弱分類（Phase 2，另外討論）

## 背景與目標

`notes/動能派學習筆記.md`（逆轟 110 篇整理）裡有一套完整的「盤面判斷 → 操作對應」邏輯（持股健檢三要素、出場三原則、盤整盤 8 步驟、大殺盤情緒點抓法等），但目前散落在筆記裡，沒有跟每天實際的盤面資料串起來。

目標：做一個每日更新的「大盤現況」區塊，把「今天盤面屬於哪一種情境」跟「這種情境下筆記建議怎麼做」直接對應起來，減少每天手動判斷、翻筆記的成本。

## 核心洞察（決定設計方向的關鍵討論）

單看大盤指數漲跌會漏掉一個常見情境：**資金塞進權值股（台積電、0050 成分股），但中小型股同時在跌，整體數字卻顯示「持平」**——這種情況體感上是災難，但用單一指標（指數漲跌）判斷不出來，且不只發生在「持平」那天，「小漲」「小跌」的日子一樣可能發生同樣的背離。

因此設計拆成**兩條獨立軸線**，不合併成單一分數：

### 軸線一：五級大盤方向

回答「今天盤面整體往哪走」。

### 軸線二：資金集中度診斷

回答「錢實際上在哪」，任何一天都顯示，不受軸線一影響。

兩條軸線分開看，才抓得住「表面持平、實際上資金正在劇烈換手」這種背離情境。

## 資料來源

Phase 1 兩個來源都要接：

1. **個股廣度**（新算，沿用既有 `daily_prices` 表，不用新爬蟲）
   - 對當天全部 universe 股票的 `change_pct` 算「上漲家數 / 總家數」比例
   - 注意：跟現有 `export/html_generator.py` 裡的 `mkt_avg`／`up_cnt`／`down_cnt`（那是**族群層級**平均，41 個族群的平均漲跌取平均）不是同一個東西，不能直接沿用，要對個股重新算

2. **真正加權指數（TAIEX）**（新爬蟲）
   - TWSE 有官方公開的每日指數 API，比照 `scrapers/twse.py` 既有的封鎖偵測模式（`TWSEBlockedError`）另外寫一支，不要重造輪子
   - 具體 endpoint 待實作階段查證

3. **權值股清單**（Phase 1 用固定清單，不接即時市值）
   - 手動維護一份 TAIEX 市值前 10-20 大成分股清單（台積電、鴻海、聯發科、台達電...等）
   - 半年 review 一次即可，不需要動態抓市值（那是選項 B，這次不做，複雜度不划算）

## 軸線一：五級大盤方向

用「加權指數漲跌幅」+「個股上漲家數比例」綜合判斷，兩個條件都符合才落在該級：

| 等級 | 指數漲跌幅 | 上漲家數比例 |
|---|---|---|
| 大漲 | ≥ +1.5% | 且 ≥ 65% |
| 小漲 | +0.3% ~ +1.5% | 且 ≥ 50% |
| 持平 | -0.3% ~ +0.3% | 不特別要求 |
| 小跌 | -1.5% ~ -0.3% | 且 ≤ 50% |
| 大跌 | ≤ -1.5% | 且 ≤ 35% |

指數跟廣度矛盾時（例如指數落在「小漲」區間但廣度不到 50%），保守判斷落到「持平」，並疊加軸線二的診斷說明原因（見下方）。

**門檻是草案，沒有回測過，實作後應該用歷史資料回測校正。**

### 各級對應筆記操作提示

| 等級 | 對應筆記章節 | 摘要 |
|---|---|---|
| 大漲 | 二、七 | 漲時加碼、找主流族群最強一檔追 |
| 小漲 | 全篇通用 | 正常操作，續抱強勢股 |
| 持平 | 七（盤整盤 8 步驟） | 均線上買、三原則出、反覆操作，不提前佈局 |
| 小跌 | 二十二（持股健檢三要素） | 均線空頭排列/下彎/跌破頸線任一項成立就先出 |
| 大跌 | 十四（大殺盤情緒點抓法）、二十三（換股實戰） | 只找最後撐住的 5-10 檔換股，不接弱勢股，不攤平 |

## 軸線二：資金集中度診斷

```
權值股平均漲跌  vs  非權值股平均漲跌
差距超過門檻（草案：1.5-2 個百分點）→ 標記「資金集中」
```

顯示範例（權值股撐盤、廣度弱）：
```
今日大盤：小漲（+0.6%）— 資金極度集中 ⚠️
├─ 權值股（前20大）：+2.1%
├─ 非權值股：-0.8%
└─ 落差：2.9 個百分點 → 錢都塞進台積電/0050，中小型在沙爛
```

顯示範例（反向：中小型輪動強）：
```
今日大盤：持平（+0.1%）— 中小型輪動強
├─ 權值股：-0.3%
├─ 非權值股：+1.4%
└─ 資金正在從權值股輪出，往中小型/主流族群移動
```

呼應筆記「資金在哪就跟去哪」（十九）、「主流類股才是第一層選股」的核心邏輯——軸線一告訴你「今天適不適合積極」，軸線二告訴你「錢實際上在哪」，兩者常常不一致，需要分開看。

## 不在這次範圍（Phase 2 或更晚）

- **個股五級強弱分類**（超強勢/強勢/平盤整理/弱勢/超弱勢，筆記「三十」）——範圍大，牽涉更多既有訊號整合（`screener/patterns.py`、`calc_meta_signals` 的 streak/均線邏輯），現有訊號強度是否足夠、要不要疊加筆記的三原則/五要件邏輯，等 Phase 1 上線、實際觀察現有訊號夠不夠力再決定
- **權值股動態市值權重**（選項 B）——先用固定清單，之後如果固定清單維護成本變高或精確度不夠，再考慮接市值資料
- **自動下單/自動判斷買賣**——這個工具的定位是資訊呈現 + 決策輔助，不是自動交易，五級分類跟診斷都是「告訴你現在是什麼情境」，不是「自動幫你決定買賣哪一支」

## 版面位置

放在 `docs/index.html` 最上方（族群排行榜之上）。理由：這個儀表板的作用是「先框定今天的判斷基準，再看族群排行」——分開成獨立頁面會讓查看變成兩個步驟，且看族群排行時會失去「現在該用哪種心態解讀」的上下文（例如大跌盤面下，排行榜漲最多的族群意義完全不同）。跟筆記「大盤先看，再看族群」的邏輯順序一致。

代價是首頁會變長一點（多一塊區塊在最上面才到族群排行榜），但比起「每天多點一次」的工作流摩擦，這個代價可以接受。
