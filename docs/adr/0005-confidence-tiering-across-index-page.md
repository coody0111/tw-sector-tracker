# 首頁全面套用信心分層，草案分類降噪成虛線標籤

**背景**：`index.html` 第一波改版（2026-08-25，13個task）驗證邏輯過關後，Cody 實際看過
重新產生的頁面覺得五級動能／溫度標籤（未回測草案分類）跟排名／漲跌%／連漲跌天數（真實
成交數字）用同一種實色徽章視覺份量呈現，導致真正有用的資訊被稀釋，且不自覺不信任/不使用
這兩個標籤。

**決定**：全站套用「信心分層」——真數字維持實色強調；未回測門檻算出的衍生分類（五級動能、
溫度、異動族群門檻、族群近況5組門檻）一律降級成虛線框＋透明底＋「（草案）」字樣的小徽章
（`.badge-weak` 風格）。詳見 `CONTEXT.md` 的「信心分層」詞條。

**why**：chips.html 已經有一套完整的「證據分級」系統（`.evid-verified`/`.evid-observe`/
`.evid-unproven`/`.evid-weak`，2026-08-25 上線），用回測結果決定視覺強度。這次不是發明
新東西，是把同一個「誠實揭露信心等級」的原則延伸到 index.html，只是空間更小（熱區格
tile 沒空間放完整證據卡/banner），所以只取用其中最輕量的 `.evid-weak` 視覺語言（虛線+
淡化），不搬整套四級系統過來。

**考慮過的替代方案**：直接把兩個標籤從熱區格拿掉（不顯示）。否決原因：資訊本身還是有參考
價值（至少能看出「系統認為這個族群動能強不強」），問題是「呈現方式讓人誤以為跟真數字一樣
可信」，不是「資訊本身沒用」，拿掉是砍過頭。

**代價**：熱區格跟族群近況現在同時存在兩種視覺語言（實色/虛線），首次看到的人需要一點時間
理解這個區分規則；已經在 `_CSS` 加了說明性 class 命名（`badge-weak`）跟一次性揭露文案
降低理解成本。門檻數值本身完全沒動，回測驗證是獨立後續任務。
