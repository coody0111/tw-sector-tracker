# index.html 重新設計 — Mockup 沿革

存放 `docs/index.html`（族群總覽頁）重新設計過程中做的 HTML mockup，依時間序保留每一版，方便換平台/換 session 後接續討論，不用重做。用瀏覽器直接開啟 `.html` 檔即可看外觀（不需要跑 server）。

## 版本

1. **2026-07-07-index-v1-flat-ranklist.html** — 第一版方向定案：扁平排行清單取代三層卡片，兩層點擊，左側排行清單＋右側明細面板，桌機/手機兩種版面。深色系（沿用 chips.html/patterns.html 既有色票）。Cody 認可此方向。

2. **2026-07-08-index-v2-anomaly-dark.html** — 新增「異動族群」模組：獨立於例行排行之外，只顯示同時符合多重訊號的族群。兩種訊號類型：
   - **爆量暴衝**：`vol_ratio ≥ 1.5` 且 `|昨日排名-今日排名| ≥ 10`
   - **連續穩步噴出**：`streak ≥ 5`（連漲≥5日）且 `cum7 > cum5 > cum3`（累積報酬持續加速）

   仍是深色系。

3. **2026-07-08-index-v3-cream-ledger.html** — Cody 要求改成米色/質感路線（提到之前有做過米色版但已遺失）。改用「財經帳冊」調性：羊皮紙米色背景、serif 標題（Georgia系）、帳冊墨藍作結構強調色（不是紅/綠，不跟漲跌撞色）、赭黃/酒紫給異動族群兩種訊號語意。刻意避開「米色+赤陶色」這種常見 AI 樣板配色組合。Cody 認可此配色方向（"這就滿像的"），但要求質感再提升、且要重新探索族群排行的呈現方式（不要只是清單）。

4. **2026-07-08-index-v4-heatmap-vs-bar.html** — 目前最新版。沿用 v3 米色帳冊配色，質感細節提升（紙紋理背景、更講究的懸浮陰影層次、更細緻的分隔線）。新增可切換的兩種族群排行呈現方式（用今天真實 41 族群完整資料）：
   - **熱區格（Heatmap）**：41 族群一次攤開，色塊深淺=漲跌幅度
   - **發散長條排行**：由中線延伸的橫條，長度=漲跌幅度，由上到下排序

   **Cody 反饋「資訊不夠多」**——具體提出想看到的資訊：突然爆發的族群跟上週的差異，以及這週表現好的族群上週表現如何。

5. **2026-07-09-index-v5-week-accel.html** — 回應上一版的「資訊不夠多」反饋。新增「本週 vs 上週」欄位：
   - 用真實資料驗算範例：功率半導體上週 -4.17%、本週 +17.76%，加速度 +21.93pt（複利計算，本週=最近5個交易日、上週=再往前5個交易日，跟現有 `cum5`/`get_rolling_returns` 的 rolling window 慣例一致，不是自然週 Mon-Fri）
   - 視覺呈現：小型雙點折線圖（slopegraph）——左點=上週、右點=本週，線的顏色隨加速方向變化（紅=加速、綠=減速），旁邊標加速度數字（百分點）
   - 熱區格跟發散長條排行都有這個新欄位；異動族群卡片的「連續噴出」說明文字也從「7d>5d>3d」改成更直白的「上週X% → 本週Y%，加速+Zpt」
   - 全 41 族群真實資料：功率半導體/機器人自動化/半導體材料 加速度最高（+21.9/+12.8/+11.3pt），被動元件/太陽能/載板 正在減速（負值）

## 尚未定案的部分

- 族群排行最終要用哪一種呈現方式（熱區格 / 發散長條 / 混合 / 都不是）
- 異動族群模組的規則門檻（`vol_ratio≥1.5`、排名跳動`≥10`、`streak≥5`）目前是經驗法則，沒有文獻依據，建議之後用歷史資料回測調整，不是拍板定案
- 排名跳動 `↑20`/`↑36` 這種裸數字呈現方式（v1/v2 沿用舊版，尚未在米色版重新設計）Cody 覺得看不懂，需要在最終版換掉
- v5 的 slopegraph 資訊密度是否夠、會不會太擠——待 Cody 看過反饋

## 技術路線提醒
