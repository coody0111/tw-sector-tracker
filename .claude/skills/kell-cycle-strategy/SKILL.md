# Kell 價格週期策略分析

使用 Oliver Kell 的**價格行為週期**框架（出自 TraderLion《波段交易大師課》全五場課程）分析股票——這是一套建立在 10/20 EMA 結構上的六階段模型，整合觀察名單篩選、超級績效型態辨識、依週期階段調整的風險管理、以及帳戶層級的投資組合建構與交易心理，用來判斷一檔股票是否值得關注、目前在其中期趨勢中所處的位置、以及該用什麼樣的進場時機與風險部位大小。

**核心理念**：價格在任何時間框架上，都會圍繞著 10/20 EMA 反覆走過「收縮→延伸」的循環，且這套循環是**碎形（fractal）**的。你不需要精準抓到絕對的頭部或底部，而是要（1）先篩出真正的領導股、（2）辨識自己身處週期的哪個階段，優先在風險報酬比最好的階段進場（楔形突破、EMA回抽站回、第一次底部突破），並（3）在出現可量化的延伸／衰竭訊號時轉為防禦或出場，同時善用金字塔加碼在確認的贏家身上放大部位。Kell 自述個人交易大約只有 30–35% 是對的〔W1 02:27〕（這是他的個人經驗，不是本 skill 的回測勝率）——獲利優勢來自於快速停損、分批加碼確認中的贏家，並讓少數幾筆真正走出 8–12 週趨勢的交易充分發揮。

> 本 skill 僅供教育與資訊用途，不構成投資建議。切勿僅憑本分析執行交易。

## 步驟 1：蒐集資料

針對目標股票及其主要指數（成長股用那斯達克/QQQ，景氣循環股用標普/SPY——選擇最能代表該股票所屬族群的指數）蒐集以下資料。可使用 yfinance、funda-data 或任何可用的市場資料工具。

**優先使用內建腳本**（需 `yfinance`、`pandas`），一次輸出下表大部分資料，包含週線延伸紀錄與市場紅綠燈判定：

```
python3 scripts/kell_data.py TICKER [INDEX]    # INDEX 預設 QQQ
```

腳本無法執行時（例如沒有網路或沒有 Python），再改用其他資料工具逐項蒐集。

| 所需資料 | 用途 |
|---|---|
| 日線價格歷史（至少6個月），含10EMA、20EMA、50SMA、200SMA | 階段辨識、均線結構 |
| 週線價格歷史（至少2年），含10週EMA、20週EMA | 延伸次數計算、高週期背景 |
| 日成交量與20日均量（20日是本 skill 自訂的分母；Kell 不確定 Finviz 用20還是50日〔W2 00:11〕） | 確認樞紐點突破／投降性拋售／Bull Snort相對量 |
| 收盤價與10EMA（日線）、10週EMA（週線）的乖離百分比 | 延伸幅度量化 |
| 近期跳空缺口紀錄（未回補的上漲／下跌缺口） | 樞紐點與動能確認 |
| 指數的同一套資料 | 指數週期關卡（步驟3）與相對強度（步驟5） |
| 距離上次財報公布的天數/週數 | 進場時機過濾條件、加碼判斷 |
| 近4季營收與EPS成長率、毛利率趨勢（本 skill 選擇收集的資料，不是 Kell 規定的資格） | 基本面品質檢查（步驟2） |
| 上市日期（若為近期IPO）、閉鎖期到期日 | IPO甜蜜點判斷（步驟2） |
| 市值、股價、平均日成交量 | 流動性與Top Dog資格初篩（步驟2） |

若部分資料無法取得，請註明並以現有資料繼續分析。缺少週線資料是重大缺口——務必特別標註，因為以下所有規則中，**週線延伸的判斷永遠凌駕於日線之上**。

## 步驟 2：領導股品質檢查——基本面與選股濾網

在進入時機判斷之前，先確認這是否是一檔值得集中曝險的標的。完整判準見 `references/leadership-criteria.md`，篩選器與觀察名單建立流程見 `references/watchlist-screening.md`。

| 檢查項 | 門檻／判準 |
|---|---|
| 營收成長率 | 至少40%，越高越好，三位數才是真正想要的；盈餘跳升但營收沒跟上是警訊。這是 Kell 對核心領導股的偏好，不是所有交易的硬門檻（他也做非 Top Dog 的快打） |
| 相對強度 | 必須跑贏大盤（Kell：可能是最重要的一項） |
| IPO階段 | 理想是上市後6–18個月、剛突破第一個大型底部；需留意鎖股期到期時間 |
| 底部整理品質 | 整理過程須有正向成交量訊號；早期底部宜緊密；晚期底部明顯變寬、變鬆是接近行情尾聲的警訊（第二個底部略鬆一點仍可交易，PTON 例〔W3 02:40–02:42〕，不是每個底部都要比前一個更緊） |
| 流動性與波動性 | 高Beta＋高流動性，走勢均勻；股價最低約$10–15，Kell 多交易$50以上 |
| 族群地位 | 是族群裡的第一名（例：比特幣題材的 COIN），不是跟漲的二線股；他也說不是不能交易 MARA 這類二線股，只是它們不算 Top Dog〔W2 02:27–02:28〕 |
| 生技股／中國股 | Kell 本人不交易（生技沒說原因；中國股：看過那些事件、而且可交易的股票太多） |

若此步驟明顯不合格（例如營收衰退、長期落後大盤、處於下降趨勢且無底部整理跡象），應在報告中明確標示為低優先級標的，但仍可繼續後續步驟供使用者參考。

## 步驟 3：市場環境——指數週期關卡

指數目前所處的週期階段，是決定個股交易該多積極的主開關。詳細內容見 `references/relative-strength.md`。

| 指數階段 | Kell 的做法 |
|---|---|
| 反轉延伸 | 先讓1–2檔已在做自己楔形突破的最強個股動起來；在看到波動收縮前不要積極 |
| 反轉延伸→楔形突破之間 | 前面的部位有效，再逐步加一兩檔，累積曝險 |
| 楔形突破（常與追蹤日重疊） | 此時最好已經建好部位；錯過了不要追，等回檔 |
| 第二次底部突破之後／指數噴出 | 週期後段：單獨看很漂亮的旗形也可能失敗；新進場視為2–5天短線、逢強賣出 |
| 楔形回落（確認修正） | 啟動修正規則：只動用**帳戶30%以下**、盡量不留倉過夜，直到**指數出現反轉延伸、且個股開始出現自己的楔形突破與型態**（不必等指數楔形突破） |

**不要求等指數楔形突破**：Kell 明說領導股常在指數真正楔形突破之前就先動，指數做反轉延伸時就可以先做1–2檔已在做自己楔形突破的最強個股；到指數楔形突破時最好已經建好部位。〔W1 01:05–01:08〕

真正要停手的是：指數楔形回落之後、**還沒出現反轉延伸**的修正途中——此時依30%規則，只動用帳戶30%以下、不留倉過夜；個股型態再漂亮，也要告知使用者指數仍在修正中。〔W1 01:09–01:10〕

同時給出**市場紅綠燈**判斷（完整規則見 `references/portfolio-construction.md`）。**以下門檻是本 skill 自訂的操作化版本，不是 Kell 原話**；Kell 本人只給了定性描述與30%修正規則：〔W1 01:09、W5 01:33–01:36〕

| 燈號 | 判定門檻（依指數） | 帳戶層級做法 |
|---|---|---|
| 🟢 綠燈 | 收在10週EMA與日線20EMA之上，且週線距10週EMA未達約7% | 積極，願意持股穿越回檔 |
| 🟡 黃燈 | 週線距10週EMA已延伸≥約7%，**或**跌破日線20EMA/10週EMA其中之一 | 低垂果實已摘完，多留現金，限制可動用的帳戶比例 |
| 🔴 紅燈 | 週線收在10週EMA之下，**且**跌破20週EMA或50日線 | 防禦：總曝險上限30%、不留倉過夜；指數出現反轉延伸後，可先做1–2檔已在做自己楔形突破的領導股（不必等燈號轉綠） |

若指數創高只靠少數權值股、羅素2000卻原地整理，代表市場廣度不足，第二梯隊容易假突破，Kell 說這「也許真的該影響你的整體曝險」（should really maybe）〔W5 00:26–00:28〕；本 skill 的做法是把它納入曝險評估、偏向保守。

## 步驟 4：個股週期階段辨識——六大階段

每檔股票都會圍繞著自己的10/20 EMA走過六個階段的循環。完整定義、量化門檻與下降版鏡像階段請見 `references/cycle-stages.md`。

| 階段 | 結構特徵 | 可操作性 |
|---|---|---|
| **反轉延伸** | 投降式低點，價格大幅跌破10EMA | **個股日線波段**不直接進場，只作提醒；Kell 只在5／15分鐘圖上做反轉延伸的反轉K棒（例如日線回到支撐時的低時間框架進場）〔W1 00:23〕 |
| **楔形突破** | 反轉延伸後第一次收復10/20EMA | **風險報酬比最佳的買進階段** |
| **EMA回抽站回** | 楔形突破後第一次拉回測試10/20EMA | **風險報酬比最佳的買進階段** |
| **底部突破（第一次）** | 較長整理（1–3週以上）於均線之上，向上突破 | 可買進，適合波段持有 |
| **底部突破（第二次以上）** | 額外的整理循環，趨勢已較後段 | 日線上視為2–5天快進快出〔W1 03:41〕；週線第二階段底部另論（W3 PTON 例），見 `references/position-sizing.md` |
| **衰竭延伸** | 價格大幅偏離10EMA上方，噴出特徵明顯 | 非買進訊號——為賣出/減碼訊號，見 `references/extension-rules.md` |
| **楔形回落** | 衰竭延伸後第一次跌破10/20EMA | 確認已做頭或至少需要重新打底——承認誤判、出清剩餘多單〔W1 01:00〕 |

上表是上升循環。股票若處於**下降循環**（楔形回落→下降段的EMA回抽被壓回→向下的底部突破→反轉延伸），請對照 `references/cycle-stages.md` 的「循環順序」與「下降循環」判斷目前走到哪一步——這決定了離下一個可操作的楔形突破還有多遠。

這是**典型順序，不一定每一步都出現**：Kell 說「不是每一步都需要走完」，也示範過沒有真正EMA回抽就轉弱、沒有明顯噴出而以停滯做頭的例子；週期也可能失敗或重置。〔W1 01:54、02:04–02:06〕

若股票處於衰竭延伸或楔形回落階段，對於日線做多進場應在此打住並告知使用者。日線上有效的做多設置是楔形突破、EMA回抽站回、底部突破。

## 步驟 5：相對強度——個股週期位置 vs 指數週期位置

完整的領先／落後框架與碎形（多時間週期）邏輯見 `references/relative-strength.md`。

個股的週期階段**必須等於或領先於**指數的週期階段：

- 指數處於反轉延伸 → 應尋找已經出現自己楔形突破的領漲股。
- 指數處於楔形突破 → 個股應已經走到EMA回抽站回或底部突破。
- 指數處於EMA回抽站回 → 個股**至少**也在EMA回抽站回，最好在高點附近打底、準備噴出。
- 聖杯級：指數修正期間個股一路走高、在指數見底時就突破新高。
- 若個股的週期階段**落後於**指數，代表這是一檔**落後股（laggard）**——即使圖表單獨看起來還不錯，也應該降低優先順序，市場上通常有更好的標的可選。
- 例外：真正的 Top Dog（尤其在第一階段底部的 IPO）可能完全不理大盤、走自己的路，短期看起來和指數不同步，不應機械地判為落後股〔W2 01:35–01:36〕。

## 步驟 6：延伸幅度分析——量化乖離程度

在把任何楔形突破／回抽站回／底部突破當作全新買點之前，必須先確認個股（與指數）**尚未**深陷延伸階段。完整門檻與「週線凌駕日線」規則見 `references/extension-rules.md`。

| 時間框架 | Kell 的心理門檻 | 第一次延伸 | 第二次延伸 | 第三次延伸 |
|---|---|---|---|---|
| 日線（距10 EMA） | 約5%（指數約4–5%），依股性調整 | 留意 | 至少部分獲利了結，Kell 常直接出清；之後常整理6–8週 | 「玩火」 |
| 週線（距10週EMA） | 超過約7%（7–8%） | 通常重新整理後再走高；指數修正約6–8%左右守住〔W1 00:56、02:08〕 | 通常引發較大修正；**預期至少6–8週震盪** | 同左，更嚴重 |

日線第二次延伸＋週線延伸，是減碼的好位置。若個股或其指數已處於週線第二次以上延伸，預期至少6–8週較震盪，日線上的楔形突破、底部突破**容易失敗、不要期待順暢的新趨勢**（週線凌駕日線）；Kell 的做法是降低期待、較積極管理獲利，例如楔形突破後「賣一些、留一些」，而不是保證不能交易。〔W1 02:00–02:01、02:09〕

**指數修正不會重置個股的延伸次數**：Kell 承認在 UPST 上犯錯——以為指數修正過就「重置了週期」而重新做多，事後看那其實是第二次延伸；確認第二次延伸後，應讓股票整理6–8週、重建結構，不是時間到就自動可買〔W2 03:02–03:05〕。

## 步驟 7：型態辨識——執行層級確認

確認具體是哪一種價格結構在支持階段轉換的判斷。完整辨識規則見 `references/patterns.md`。

| 型態 | 確認的階段 | 關鍵特徵 |
|---|---|---|
| 多頭旗形/三角旗（Bull Flag/Pennant） | 楔形突破／回抽站回的延續 | 約3–5根K棒的收斂拉回（大約數，不是硬篩選），理想上量縮；不買離10日線太遠的 |
| 點火K棒（Ignite Bar） | 持有中的停損管理（W1／W4） | 明顯異常的寬區間K棒，尤其帶量時；通常把停損上移到它的低點（量很小的仍會上移，但要懷疑它可能失敗〔W4 00:25–00:29〕） |
| 突破缺口（BGU） | 從大型底部發動 | 一定要有好的底部、量是絕對必要；理想上做從長期底部出來的第一次跳空（已延伸、跳空過兩三次的常是竭盡缺口）；可買跳空或突破第一天高點 |
| 財報後旗形 | 從底部帶量跳空後 | 回檔一兩天到10日線附近形成小旗形再突破（不一定剛好碰到均線〔W3 00:50〕）；Kell 可能最愛的型態；第一天被停損也可回頭、常買更大 |
| 下降通道／下降楔形 | 幾乎總是同時是楔形突破 | 數週更低高低點（週線上像旗形），要緊、均勻；通道末端出現更高低點或守住前一根低點，楔形則是跌破前低又收回（scum）約兩次 |
| 平台底／帶柄杯型／雙底 | 大型底部 | 底部越大空間越大；杯深要對照大盤（大盤只跌10%卻有50%深的杯，可能是死亡大碗）；雙底低點的洗盤＝2B反轉 |
| 內縮K棒（Inside Bar） | EMA回抽站回／底部突破 | 整根K棒落在前一根K棒範圍內，量越輕越好 |
| 影線交易（Wick Play） | EMA回抽站回／底部突破 | 前一根K棒留下上影線，下一根是**整根落在該影線範圍內**的內縮K棒（最好量縮）；技術上的觸發是突破影線高點，Kell 實務上常在內縮K棒高點被突破時就進場 |
| 外側反轉（Outside Reversal） | 買上升趨勢中的回檔 | 回檔2–5天到10/20日線，跌破前一日低點後拉回穿過它，停損當天低點；不在短期均線附近，他大概不做 |
| 有瑕疵的底部（Faulty Pattern） | 警示訊號 | 「匕首式賣壓」→避開6–9個月；晚期底部變寬鬆；大贏家幾乎都從200日線之上開始 |

僅有階段判斷、缺乏型態支持的訊號較弱；優先選擇階段與型態互相印證的設置。依型態區分的精確樞紐點位置見 `references/entry-rules.md`。

## 步驟 8：進場點與停損設定

完整的10點買進檢查清單、時間框架優先順序（月線＞週線＞日線＞盤中）、樞紐點機制與時機規則見 `references/entry-rules.md`；完整停損演進（初始三步＋後續上移工具）、點火K棒/EMA/趨勢線/時間停損見 `references/stop-loss-management.md`。

- **樞紐點（pivot point）**＝一個具體價位，突破它應該會帶來真正的延續走勢——而不是機械式的均線穿越點；依型態不同，精確位置也不同（見entry-rules.md對照表）。
- **買進觸發**：價格在型態（步驟7）支持下**突破事先定義的樞紐點**，可在盤中執行（Kell 用市價單，有些楔形突破開盤就進）〔W1 03:23–03:25、03:47–03:48〕。**量能要求依型態而定**：楔形突破這類買點，沒量也會進場，有量更有信心加碼〔W1 00:34–00:35〕；但**突破缺口（BGU）的量是絕對必要**〔W3 01:09〕，不能用前一句覆蓋（見步驟7與 entry-rules）。不確定時先買部分倉位。
- **初始停損**：設在樞紐點下方／觸發K棒的低點下方——絕不是憑空選一個固定百分比。
- **停損演進**：最大痛苦停損（碰到就走、不等收盤）→ 突破當天低點 → 損益兩平區 → 用「再確認」機制持續上調；趨勢走出來後再看它尊重10日或20日線、趨勢線（完整規則見stop-loss-management.md）。
- **賣出**：均線、趨勢線停損是保護；逢強賣出看延伸（日線第二次延伸＋週線延伸時減碼），可分批 1/4–1/3；一定會出現的楔形回落是最後防線。
- **風險報酬比**：Kell 說至少要瞄準3:1或5:1，而他自己一年有幾筆能做到20–30倍風險、那幾筆決定全年績效〔W3 00:13〕。
- **時機過濾**：不在財報前夕直接建新倉（頂多小部位）；財報後的跳空與財報缺口旗形反而是 Kell 最愛的型態〔W3 00:45–00:50、02:57〕。最佳執行時段是開盤後與收盤前各約1–1.5小時；開盤後最初15–25分鐘容易假動作，除非型態或催化劑很明確〔W1 03:45–03:47〕。

## 步驟 9：倉位大小與依階段調整的風險管理

完整公式、停損演進摘要、金字塔加碼具體範例、洗盤後加碼規則見 `references/position-sizing.md`。

```
股數 = (帳戶資產 × 單筆風險%) ÷ (進場價 − 停損價)
```

這算出的是**計畫風險**：低流動股可能閃跌、實際成交遠低於停損〔W4 04:27–04:28〕。

單筆風險與預期持有時間都應該隨進場時所處的週期階段而調整——同一檔股票在楔形突破進場，跟在第二次底部突破進場，本質上是不同性質的交易：

| 進場階段 | 部位性質 | 風險態度 |
|---|---|---|
| 楔形突破／EMA回抽站回 | 多週波段持有（持有意圖） | 願意持股穿越正常回檔；初始倉位仍依停損距離與信心決定，常先買部分、確認後加碼〔W1 00:44–00:46〕 |
| 底部突破（第一次） | 多週波段持有 | 同上；可在均線附近先買部分，真正突破再加碼〔W1 00:39–00:41〕 |
| 底部突破（第二次以上） | 日線上視為2–5天快進快出〔W1 03:41〕；週線第二階段底部另論（W3 PTON 例） | 現金流交易，週期這麼後段最不想虧錢〔W1 03:42〕；短線可能就在第3、4天逢強賣（原話 maybe）〔W4 01:40–01:41〕；縮小倉位、收緊停損是本 skill 的推論 |
| 訊號不夠明確／試探性 | 試單 | 正常倉位的一半（例如帳戶的7.5% vs 15%） |

### 這檔在帳戶中的定位

單筆倉位之外，還要放回整個帳戶來看（完整規則見 `references/portfolio-construction.md`；數字是 Kell 的個人參考，不是標準答案〔W5 00:02–00:12〕）：

| 部位類型 | 無融資目標佔比 | 判斷依據 |
|---|---|---|
| 首選標的（Top Idea） | 15–20% | 前2–3名，有主題、相對強度極佳、**突破大型底部** |
| 高信心核心（Conviction Core） | 10–15% | 首選標的「差一級」 |
| 高波動高信心核心 | 5–7.5% | 同等品質但ADR高、流動性差、價差大——需要較寬停損，所以倉位必須縮小 |
| 核心（Core） | 約7.5% | 第二梯隊、較晚突破，但理想上仍是市場前10名左右 |
| 波段部位（Swing） | 5–7.5% | 週期後段的短整理突破，也許漲3–5天左右就逢強減碼（概略例子，不是硬到期） |

- **目標倉位決定初始倉位**：例如首選標的目標20%，初始約12.5%→加碼5%→補2.5%；初始單筆風險一般在帳戶約0.3–0.5%（他的一般範圍，不是硬上限也不是下限：同一場他舉20%部位×1%停損＝0.2%）〔W5 00:15–00:18〕。
- **帳戶本金風險預算**：加總所有部位「全部打到停損」的帳戶虧損%，設一個上限（1–3%因人而異）。等既有部位停損移到損益兩平、**整體**本金風險下降、預算有餘裕時，才新增下一檔（他的例子是兩檔已進獲利、一檔還沒，整體剩約30bp，就再加兩檔各25bp）〔W5 00:22〕。年初沒有獲利緩衝或正處於回撤時，他會考慮少承擔一些風險（原話 maybe）〔W5 00:24–00:25〕。
- 持股檔數：Kell 說8–10檔就能滿倉，必要時到13–15檔，重點是持有的是不是市場上最好的股票〔W1 01:53〕；他在6–10檔時交易最好，**超過12檔**常是快有糟糕一天的訊號，到13、14檔還想加就先賣一檔〔W2 01:15、02:41–02:43〕；「手上檔數變太多」本身他也當成該賣一些的警訊〔W5 00:30〕。

若訊號明確且信心高，可規劃**金字塔加碼**：先用小倉位、緊停損建立初始部位，隨確認訊號（旗形突破、再次樞紐突破）逐步加碼，同時把已有部位的停損拉高，讓第一批的未實現獲利承擔加碼的風險——用大約同一份本金風險換到兩倍部位；最好在行情開始的前2–3天左右完成（原話 or so；重點是靠近初始樞紐、控制成本，不是第4天就不能加）（具體數字示範見position-sizing.md）。

## 步驟 10：回覆使用者

**歸屬規則（每次回覆都要遵守）**：
- 寫成「Kell 說／Kell 認為／Kell 的經驗／他提醒」的內容，必須能在 references 找到；找不到的就是你自己的推論，要寫成「依此推論」「我的判斷」，不可歸給 Kell。
- 轉述時保留原話的程度：references 寫「也許、可能、大概（probably）、有時、舉例」的，不可升級成「常見、通常、一定、規定」。
- references 裡附帶的例外與但書要一起帶上（例如「財報前不建新倉，頂多約1/5部位」「蹲一兩天要不要抱看裁量」），不可只留主規則。
- 數字要分清楚是哪一種：目標倉位與初始倉位、帳戶%與持股%、帳戶風險與停損距離。

以下列結構呈現分析報告：

### 報告結構

1. **領導股品質**：步驟2的基本面與選股濾網檢查結果，是否為值得優先關注的標的
2. **指數週期關卡**：指數目前階段、步驟3的曝險建議
3. **個股週期階段**：目前所處階段，並附上支持該判斷的日線/週線證據
4. **相對強度**：領先、同步或落後指數，並說明理由
5. **延伸幅度檢查**：日線與週線距10EMA/10週EMA的乖離百分比、延伸次數、是否觸發週線凌駕日線的例外規則
6. **型態確認**：目前是否有執行層級型態支持（若有，是哪一種），以及樞紐點價位
7. **進場計畫**：樞紐點價位、觸發條件、初始停損、是否適合分批建倉/加碼
8. **倉位大小與帳戶定位**：依公式計算出的股數/風險金額、對應到哪一列的階段分級表、這檔屬於哪一種部位類型（首選標的/高信心核心/…）與目標佔比。**只有結論是「可操作的做多設置」時**才需要計算；若使用者未提供帳戶規模、風險承受度、目前持股與整體本金風險，此時再主動詢問。結論是觀察名單或不建議進場時，略過計算，只說明若之後成形會屬於哪一種部位類型。
9. **總結判斷**，三選一：
   - **可操作的做多設置** — 領導股品質、階段、相對強度、延伸幅度、型態五者一致（這是本 skill 只針對核心領導股的做法；Kell 本人也會做非 Top Dog 的短線快打，遇到這類情況要說明它不屬於核心持股、改用快打的管理方式）
   - **觀察名單** — 階段正確但型態/樞紐點尚未確認，或觸發了第二次延伸的警示，或領導股品質中等
   - **不建議進場** — 階段錯誤（衰竭延伸/楔形回落）、落後指數、領導股品質不合格，或指數環境不利

   結論是「觀察名單」或「不建議進場」時，**必須列出轉為可操作所需的條件**，依週期順序寫成檢查清單，條件要依目前結構挑選（例如原本在高檔整理的領導股，不需要先跌出投降低點，只要等它自己的樞紐突破）。下降循環中的例子：①出現反轉延伸（投降式低點、大幅跌破10EMA、放量），並指出可能的支撐區；②波動收斂、10/20EMA靠攏後，突破由K棒建立的樞紐點、站回均線（楔形突破）；③指數至少已出現反轉延伸（**不必等指數楔形突破或燈號轉綠**——領導股常先於指數發動），且個股自己的楔形突破成形；若指數仍在楔形回落後、尚未反轉延伸的修正途中，則依30%規則限制曝險。讓使用者知道該等什麼，而不只是「現在不行」。

10. **紀律提醒**（一兩句即可，針對當下情境）：例如紅/黃燈環境提醒不要過度交易、剛被停損的股票提醒「可能錯兩三次才抓到行情」（但若結構已破壞、不再出現新買點，依他的規則就不太會再考慮買〔W5 02:18–02:19〕）、已延伸時提醒「你覺得要避險，就直接減碼」。

最後務必附上聲明：本分析僅供教育用途，不構成投資建議。
