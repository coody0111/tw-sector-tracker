# 進場規則

出自 Oliver Kell《波段交易大師課》Webinar 3：超級績效型態。〔W3 時:分〕為字幕出處；少數取自其他場次者另註。

## 時間框架〔W3 00:06–00:07〕

- **高時間框架凌駕低時間框架。** 月線很重要，**週線是錨**；日線用來精修型態、管理交易（他是中期交易者，較長線的人可以用週線管理）；**盤中圖用於風險管理**。
- **不要在5分鐘圖上找機會**——會把自己切碎、過度交易。週線或日線沒有型態，看盤中圖沒意義，那筆交易走不遠。
- 盤中圖的用法（第1場）：價格到了日線上要執行的區域（樞紐或支撐區）時，放大到15／5分鐘進場；進場後可把管理逐步升級到小時線、日線；盤整市可改用小時線交易。〔W1 00:18–00:19、03:39、03:55–03:57〕
- 他自己正把最低時間框架從15分鐘移到**小時線、4小時線**，以減少交易次數、專注大行情。〔W3 03:06–03:07、03:33–03:34〕
- 「**進場像當沖客，持有像部位交易者**」（導師的話）。〔W3 02:45〕

## 買進檢查清單〔W3 00:07–00:16〕

他說自己不會真的逐項打勾，但腦中一定會想過：

1. **是否從月線／週線的大型整理出來？** 尤其從修正出來時，要買有底部的型態——底部是真正的支撐，突破才有行情。
2. **相對10週EMA的位置**：離10週線很遠時，突破成功率較低，成功了也走不遠。（50日SMA和10週線大致可互換，都是參考點）〔W3 00:24〕
3. **股性轉變**：通常由量呈現——Bull Snort 或從底部大跳空；之後就從這個點開始交易這檔。
4. **相對強度與指數週期**：指數已漲8–10週，某檔才剛突破、整段都落後，成功率低於在指數反轉延伸時就突破的股票。
5. **日線型態（型態中的型態）**：例如6個月的底部裡，在日線上找波動收縮，精修時機與風險。
6. **細微線索**：內縮K棒、**量縮**、很小的未回補缺口——多數人不會注意。
7. **共振**：週線、日線、當沖客看的內縮K棒……多種參與者都在看同一個點（從 Trader Florida 學來）。
8. **催化劑**：不一定有，但六到九個月的長底部常需要某個事件推出去；他99%是財報，也可能是新聞、新產品、FDA。
9. **上檔是否值得風險**：停損要10%卻只能賺20%，他沒興趣；冒3%去賺30–100%才是好機會。至少要瞄準**3:1或5:1**（這是進場前評估上檔空間，他自己**不設固定停利目標**：「I don't actually use targets myself」〔W3 00:16〕；上檔看離10週線多遠、左側有沒有壓力）；他一年有幾筆能做到**20–30R**、那幾筆決定全年，其他很多交易「很普通」。
10. **左側有沒有壓力、是否創新高**：有壓力的他也做，但當作較短的波段；有大壓力的股票要**6–9個月以上**的底部才會真正跟進（套牢者要時間放棄）。最好是在新高、或距高點**10–15%以內**的股票。健康的底部多半不超過30%修正（大盤跌30–35%時例外）；**底部越緊越好**。

## 其他選股前提

- 不需要抓那頭20–30%：好股票終究會創新高（一位老手在他做 FSLY 時這樣告訴他）。〔W3 00:18〕
- **IPO 甜蜜點：上市後6–18個月，可能到24個月**——此時買的人都是新的機構買家，他們「不會花兩週買，會花兩年買」。已走完一輪的股票（如 PTON、ROKU），在再次創新高前就是「被打爛的貨」。〔W3 00:19–00:20〕
- 左側壓力看多遠：**近6–9個月內**看得到明顯出貨，就不是最高潛力的情況；**跌破高點40%以上**，通常有一段時間是受損商品，即使反彈也常有更好的選擇。〔W3 00:21–00:22〕
- 最好的買點：反轉延伸到200或50日線附近，整理出型態，在離50日線不遠處楔形突破——不延伸，上檔空間大。他偏好在50日線之上交易。〔W3 00:22–00:23〕

## 樞紐點的位置

樞紐點是一個具體價位：突破它應該會延續；失敗則出場。均線只用來定位，**不單獨構成觸發價**——要用價格高低點或整理區建立樞紐。〔W1 00:29、02:22；W3 00:02–00:03〕

| 型態 | 樞紐點 | 出處 |
|---|---|---|
| 多頭旗形／三角旗 | 突破旗形的下降高點（原話 break through those lower highs；不一定等於整面旗形的最高價） | W3 00:26、00:32 |
| 突破缺口（BGU） | 直接買跳空，或突破**跳空第一天的高點** | W3 00:39–00:41 |
| 財報後旗形 | 回檔小旗形的高點（可先在均線附近分批） | W3 00:50–00:51 |
| 下降通道／楔形 | 末端收緊後建立的樞紐高點，通常同時突破下降趨勢線、站回均線（楔形突破） | W3 00:58、01:06 |
| 平台底 | 底部上緣的短期收縮突破 | W3 01:12–01:13 |
| 帶柄杯型 | 把手頂部 | W3 01:18 |
| 內縮K棒 | 內縮K棒的高點（連續多根通常取最近一根） | W3 01:43–01:45 |
| 影線交易 | 技術上是影線高點；實務上常在內縮K棒高點被突破時就發動 | W3 01:28、01:34–01:35 |
| 外側反轉 | 回穿前一天低點的位置，停損在當天低點 | W3 01:40、01:46–01:47 |

## 觸發與量

- 突破事先定義的樞紐點即可在盤中執行（市價單）；跌回樞紐下方＝分析錯，出場再等下一次。〔W1 03:23–03:25、03:47–03:48；W3 00:32〕
- **量**：
  - 突破缺口（BGU）——量是**絕對必要**。〔W3 01:09〕
  - 其他型態——不一定看到大量，沒量他也會做；有大量代表機構積極，他會更積極買。〔W3 01:09〕
  - 更重要的是**研究型態形成過程中的量**，那才是真正的優勢。〔W3 01:10–01:11〕
- 越貼近樞紐買越好：2.5%停損若追到6%，同樣3:1的風險報酬就要18%才達到，而且倉位要縮小。〔W1 03:33–03:34〕

## 初始停損

- 「最大痛苦停損」設在突破前的小整理區（平台）下方；突破成立後移到突破當天低點。由「買進理由在哪裡失效」決定，而不是固定百分比。〔W3 00:32–00:36〕
- 完整停損規則見 `stop-loss-management.md`。

## 時機

- **財報**：不在財報前夕直接建新倉（頂多買「約1/5部位」——原話 one-fifth position or something，沒說分母，不要換算成帳戶20%）〔W3 02:57〕；財報**之後**的跳空與財報後旗形是他最愛的型態之一〔W3 00:45–00:50〕。持股要不要抱過財報，見 `position-sizing.md`。
- 一天中：開盤後與收盤前各約1–1.5小時最好；中段（美東約11:30–14:30）多是量縮盤整；**開盤後最初15–25分鐘**容易假動作，除非型態或催化劑很明確。〔W1 03:45–03:47〕

## 沒觸發、或被洗出場時

- 樞紐沒觸發＝時機未到，等下一個。AFRM 例：在指數修正中，可做的點試了好幾次都只小賺小賠；真正的行情在指數見底當天或隔天，它從緊密的下降通道帶量突破、第一次回到20 EMA就守住（他說20 EMA常是最強股票守住的均線）——**常要試好幾次才抓到**，重點是每次都小虧。那一筆 Kell 自己沒扣扳機，他說這也是功課的一部分。〔W3 02:07–02:14〕
- 被洗出場後**不要追**：好股票會再給你位置；追高常買在頂、回檔又賣在低。看錯就承認，等下一個點，期間去做別的機會。ABNB 例：他承認被洗出是因為**看太近**（盯5分鐘圖），股票其實連10日線都還沒測試——這也是他不再看5分鐘圖的原因之一。〔W3 03:34–03:39〕

## 週線交易（給沒時間盯盤的人）〔W3 02:38–02:46〕

- 所有型態（內縮K棒、影線交易等）在週線上都有效，甚至可能更好。PTON 週線示範：假設從約$40抱到約$130——依這兩個價格算漲幅約225%；字幕他口述「about 300%」，與示例價格對不上〔W3 02:43–02:44〕。Darvas 也是這樣用延遲的資料交易。
- 週線的停損比較寬，規則一樣，所以倉位可能要小一點；或者先用日線管理風險，行情走起來再改用週線管理。
