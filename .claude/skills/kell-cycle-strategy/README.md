# Kell 價格週期策略分析

使用 Oliver Kell 的**完整交易方法論**分析股票——出自 TraderLion《波段交易大師課》全五場課程：(1) 市場週期精通、(2) 尋找真正的市場領導股、(3) 超級績效型態、(4) 風險與部位管理、(5) 系統建立、心態與交易心理。這是一套建立在10/20 EMA結構上、跨時間框架碎形適用的六階段框架，整合觀察名單篩選、型態執行、依週期階段調整的風險管理、帳戶層級的投資組合建構與交易心理，用來判斷該關注哪些股票、波段交易的進場時機、相對強度、風險部位，以及整個帳戶該怎麼配置與檢討。

## 觸發情境

- 提到 Oliver Kell、TraderLion、價格行為週期
- 楔形突破、楔形回落、EMA回抽站回、底部突破/築底突破、衰竭延伸、反轉延伸
- 10/20 EMA 波段交易、跨時間週期的碎形價格循環
- 判斷股票或指數目前處於上升/下降趨勢的哪個階段
- 判斷股票是否「乖離過大」、延伸次數是否過多
- 比較個股相對指數的週期階段強弱（是否為落後股）
- 建立/篩選觀察名單、找真正的市場領導股（Top Dog）、Bull Snort等篩選器
- 評估樞紐點、型態（影線交易、下降通道、多頭旗形等）、停損與金字塔加碼
- 「這個回檔該不該買」「這個突破該不該追」「這算不算真正的領導股」等波段交易情境提問
- 帳戶要持有幾檔、各佔多少（首選標的/高信心核心/核心）、整體本金風險、修正後多快建倉
- 交易檢討、交易日誌、型態資料庫、研究歷史先例
- 交易心態問題：過度交易、報復性交易、不敢扣扳機、連續虧損、建立自己的交易系統

## 這個 skill 會做什麼

1. **領導股品質檢查** — 基本面濾網（營收成長偏好）、Top Dog準則、IPO階段、底部整理品質
2. **指數週期關卡** — 判斷指數（那斯達克/標普）目前的週期階段，作為決定曝險積極度的主開關
3. **個股週期階段辨識** — 判斷個股目前處於六階段中的哪一個，並給出可操作性判斷
4. **相對強度檢查** — 確認個股的週期階段是否領先或至少同步於指數，避免誤買落後股
5. **延伸幅度判斷** — 參考 Kell 的乖離心理門檻（日線約5%、週線約7–8%，依股性調整），人工判斷第幾次延伸，套用「週線凌駕日線」規則；腳本列出的超門檻區段只是候選事件，不是 Kell 定義的計數算法
6. **型態辨識** — 確認多頭旗形、下降通道、影線交易、外側反轉等執行層級型態是否支持階段判斷
7. **進場點分析** — 依10點檢查清單與時間框架優先順序，計算樞紐點價位、觸發條件、停損演進
8. **倉位大小與風險管理** — 依風險百分比計算股數，套用依週期階段的持有/停損策略，並規劃金字塔加碼
9. **投資組合定位** — 判斷這檔屬於哪種部位類型與目標佔比，搭配帳戶本金風險預算與市場紅綠燈調整整體曝險
10. **系統與心態教練** — 回答交易檢討、型態資料庫、交易心態類問題，並把弱點轉成具體的交易規則

## 適用平台

全平台（Claude Code、Claude.ai 及其他 agent 皆可使用）。`scripts/kell_data.py` 需要網路與 Python，只能在 Claude Code 等 CLI 型 agent 上執行；在 Claude.ai 上請改用其他資料來源或由使用者提供圖表。

## 設定需求

無需特殊設定。搭配 yfinance、funda-data 等市場資料工具取得即時價格與均線資料時效果最佳。

內建 `scripts/kell_data.py`（需 `pip install yfinance pandas`），可一次輸出均線、乖離、週線延伸紀錄、相對強度、基本面與市場紅綠燈：

```
python3 scripts/kell_data.py AVGO        # 指數預設 QQQ
python3 scripts/kell_data.py XOM SPY
```
