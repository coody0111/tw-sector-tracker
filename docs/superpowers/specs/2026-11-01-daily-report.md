# 每日報告（2026-11-01 與 Cody 定案）

## 目的
每個訊號日出一份報告，給下一個交易日開盤前使用。

## 決定
- 形式：新頁 `docs/report.html`（永遠最新）＋`docs/reports/YYYY-MM-DD.html`（全部保留），頁面有日期選單。導覽列加「每日報告」。
- 內容順序：今日重點、大盤、籌碼、族群、個股推薦、明日觀察。
- 今日重點：固定規則產生 3 句，不用 AI，數字與下方表格同源。
- 期限：下一個交易日前一晚 24:00 前。週五最晚週日晚上（等集保）。
- 平日 23:45 資料未齊：照出報告，推薦標「暫定：缺 X」，只用已到資料；隔天 08:00 到齊後更新，訊號增減或撤回由 Telegram 通知。
- 同一天更新覆蓋檔案，只留最新版。
- Telegram：推薦訊息改成今日重點＋報告連結；資料更新通知照舊；盤中訊號與 15:00 收盤摘要不變。
- 籌碼金額為股票池合計（約 1,036 檔），頁面需標明，不是全市場官方總額。

## 大盤區
加權收盤與漲跌、對 20 日線、站上 MA20 比例、突破失敗率、漲跌停家數。

## 籌碼區
外資、投信合計買賣超（億）；外資＋投信買超與賣超前 5 族群；融資增減；週資料更新時加大戶增減。

## 定案補充
- 大盤判定（第 7 題 A）：加權在 20 日線上且站上比例 ≥ 50% → 偏多；兩者皆否 → 偏空；其他 → 中性。只描述現況，未回測，不是進場開關。
- 新訊號買幾股用推薦頁存的總資金（瀏覽器），未輸入時 100 萬。
- 已知限制：暫定版若到隔天 08:00 後資料才到，隔天晚上已換新訊號日，不會回頭更新（維持暫定標示）。

## 上線前需要

- 排程新增 23:45 觸發，需 Cody 以系統管理員權限重裝。
