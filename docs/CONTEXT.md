# tw-sector-tracker

台股產業族群（MoneyDJ 分類）每日漲跌幅追蹤與訊號掃描系統。輸出四個靜態頁面：族群總覽
（`index.html`）、籌碼分析（`chips.html`）、形態掃描（`patterns.html`）、逆轟策略
（`momentum.html`）。

## Language

**信心分層 (Confidence Tiering)**：
UI 上明確區分「真數字」（已成交/已發布的原始數據，如漲跌%、連漲跌天數、法人買賣超張數）
跟「草案分類」（依經驗法則門檻算出、尚未回測驗證的衍生分級，如五級動能、溫度標籤、異動
族群門檻）——前者用實色強調，後者用虛線框＋透明底＋「（草案）」字樣降噪，避免未驗證的
分類跟真數字搶視覺份量。這是 chips.html 既有「證據分級」系統（`.evid-verified` /
`.evid-observe` / `.evid-unproven` / `.evid-weak`）的精簡延伸，套用到空間較小的熱區格
場景，不放完整證據卡/banner。
_Avoid_: 證據分級（那是 chips.html 特定的四級完整系統名稱，這裡是簡化版，不要混用同一個
稱呼造成誤會）

**草案標籤 (Draft Label)**：
信心分層裡「低信心」那一端的具體 UI 元件——虛線框、透明底、比真數字小一號字級、帶
「（草案）」字樣的小徽章。用在任何門檻未經回測驗證的衍生分類上。
_Avoid_: 徽章（太籠統，站上還有很多其他種類的實色徽章，如外資連買徽章、量能徽章，那些是
真數字不該套這個樣式）

**今日/本週異動 (Today/This-Week Movements)**：
`index.html` 的一個區塊，把原本分散在三個地方、但本質都是「族群層級發生了變化」的訊號
合併呈現：異動族群、今日爆發、融資背離警示、連續漲停鎖死（以上四個都是今日單日事件）、
轉折點、排名進出榜（以上兩個是本週尺度）。內部依時間尺度分兩層（今日層／本週層），今日層
都是真數字用實色，本週層都是未回測門檻用草案標籤。「今日爆發」原本歸在「族群近況」6大類
之一，但它跟族群近況「週度趨勢」的定位矛盾（本質是單日事件），移進這裡才名實相符。
_Avoid_: 異動族群（那是這個區塊底下今日層的其中一個子項目，不是整個區塊的名字，範圍容易
混淆）

**融資背離警示 (Margin Divergence Alert)**：
個股層級訊號，比較近期融資餘額趨勢跟股價趨勢方向是否背離。`bearish`＝融資餘額持續增加但
股價持續下跌（散戶越攤越貧的警訊）；`bullish`＝融資餘額持續減少但股價持續上漲（籌碼去
槓桿的健康訊號）。命名上 bearish/bullish 指的是這個背離現象本身對後市的意涵，不是「融資
增加」或「融資減少」這個動作本身的方向，容易搞反，引用時要小心。
_Avoid_: 融資趨勢（太籠統，沒表達出「背離」這個核心語意）

**連續漲停鎖死 (Consecutive Limit-Up Lock)**：
個股層級訊號，抓還在連續鎖漲停狀態的股票，含連續天數、量能是否遞減、起漲當天是否確認
爆量三個維度。跟「爆量暴衝」（異動族群裡的訊號）不同：那個抓的是排名跳動+爆量的組合，
這個抓的是實際鎖死漲停這個更直接的市場現象，兩者可能同時發生也可能不會。
_Avoid_: 漲停股（太籠統，沒表達出「連續」跟「鎖死」這兩個關鍵限定條件）

## 頁面間資料重用慣例

**跨頁訊號重用 (Cross-Page Signal Reuse)**：
四個頁面共用同一批 `processors/`／`screener/` 底層計算函式，但各頁面的產生器
（`export/*_generator.py`）過去各自只挑自己需要的訊號餵進頁面，同一支函式的輸出可能只
被其中一兩個頁面用到，其他頁面完全沒有引用。第二波首頁改版第一次刻意「跨頁借用」
momentum.html／patterns.html 專用的訊號函式（`get_margin_divergence()`、
`scan_consecutive_limit_up()`）餵進 `index.html`——這是有意識的架構選擇，不是意外耦合，
見 `docs/adr/0005-index-reuses-cross-page-signal-functions.md`。
