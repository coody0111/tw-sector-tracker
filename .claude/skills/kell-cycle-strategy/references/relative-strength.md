# 指數週期與相對強度

出自 Oliver Kell《波段交易大師課》Webinar 1：市場週期精通。〔W1 時:分〕為字幕出處。

## 指數的選擇

- 交易科技成長股 → **那斯達克（QQQ）**；交易金融、石油等景氣循環股 → **標普500**。〔W1 01:10〕
- 指數走價格週期非常規律；分析指數的目的是**更好地執行個股**，而不是交易指數本身。〔W1 01:04、01:13〕

## 波動度

- 市場在**波動擴張**時見頂和見底；在可持續的走勢之前，會先出現**波動收縮**。在看到收縮之前不要積極，否則只會在高波動中被來回洗。〔W1 01:05〕
- 極端修正中（例如COVID），個股根本不會有型態可交易；要等波動收斂、型態成形。〔W1 01:27〕

## 圍繞指數反轉延伸建立曝險

- **領導股常在指數真正楔形突破之前就先動**：指數還在做反轉延伸、打底時，最好的股票已在出現自己的楔形突破，這些就是可以做的設置。〔W1 01:05–01:06〕
- 節奏：指數做反轉延伸時先讓1–2檔股票動起來；它們有效，再加一兩檔；在指數反轉延伸到楔形突破之間的幾週內逐步加曝險。〔W1 01:06–01:07〕
- **到指數楔形突破時（常和所謂的「追蹤日」重疊），你最好已經建好部位**；這樣更能抱過正常回檔、持有數週。若錯過了，沒關係，耐心等回檔，不要追。〔W1 01:08〕
- 修正期間建立觀察名單：找**抗跌**（跌得比市場少）的股票；跟指數一起狂跌的不用看。〔W1 01:28〕
- 但不能只看跌幅百分比：成長股波動大，跌幅可能比指數多，卻仍在做出更高的低點、結構比指數強——這也是相對強勢。要比較同一段時間的結構（指數創更低的低點、個股守住更高的低點）。〔W2 00:47–00:48〕
- 判斷指數是否真的見底，**最好的指標是個股是否開始突破**。一般5–8%的修正中，指數見底附近就會看到個股突破；極端修正時則要晚一點。〔W1 01:30〕
- 若指數楔形突破時，個股上看不到可交易的型態，這個楔形突破多半會失敗。〔W1 01:34、03:15〕
- 指數通常要**先測試20日線、回檔幾天**，再突破才是可持續的底部；很少直接穿過20日線就一路漲。〔W1 01:32〕

## 核心規則：個股的週期要領先指數

指數出現楔形突破之後，用週期判斷相對強度：〔W1 01:07–01:08〕

| 指數所處階段 | 個股至少應該在 |
|---|---|
| 楔形突破 | EMA回抽站回或底部突破 |
| EMA回抽站回 | **至少**EMA回抽站回，最好在高點附近打底、準備噴出 |

- 指數已做EMA回抽站回、個股才剛楔形突破＝**落後股**。你會買它們通常是因為錯過了領導股、心裡著急——但這樣交易的就不是市場上最好的股票。〔W1 01:07〕
- 例：指數已楔形突破、PLTR 卻毫無動靜＝落後股，就算它之後也楔形突破，Kell 預想它可能漲到圖上某個位置就再度回落（他也說「我可能看錯」）；其他股票會是更好的機會。〔W1 03:27–03:28〕
- 週期後段，若指數正在噴出，即使某檔股票的多頭旗形單獨看很漂亮，也可能要避開，因為容易失敗。〔W1 00:49〕

## 聖杯級設置

- 指數剛從低點出來時，某檔股票在整段修正中一路走高、已經在打底部突破、在指數見底時直接突破新高——**這是最理想的情況**（例：2020年的ZM）。〔W1 03:42–03:43〕

## 修正期間的規則（30%規則）

- 指數出現楔形回落（確認進入修正）時，啟動你的修正規則。〔W1 01:09〕
- Kell 的規則：**只動用帳戶30%以下的資金，而且盡量不留倉過夜**——修正中常是大幅跳空開低、盤中拉高、隔天又跳空開低，把獲利全吐回去。〔W1 01:09–01:10〕
- 用規則讓自己留在場外，**直到指數出現反轉延伸、而且個股開始出現楔形突破和其他型態**為止——條件是**個股**的楔形突破，**不必等指數本身楔形突破**（原話：“until you start to see that index reversal extension and wedge pops and other setups building on individual names”）。〔W1 01:10〕

## 其他觀察

- 週末掃描月線：修正中若多數月線仍健康、只是需要時間，指數出現反轉延伸時可更積極；其他族群（即使你不交易）也在打底，市場就不太會瀑布式下跌。〔W1 00:19–00:20〕
- 主持人 Richard 補充的一種簡單判斷（非 Kell 本人所說）：指數跌破20 EMA，個股仍守在其上。〔W1 01:12〕
- 正常環境中，要交易在高點附近、領先市場的股票；50日線、200日線都已下彎的股票（例如當時的BABA）是落後股，不值得花時間。〔W1 01:51–01:53、03:03〕
